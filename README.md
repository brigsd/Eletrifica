# 🏆 Guia de Achievements do GitHub

Repositório usado para destravar os achievements (conquistas) do perfil do GitHub.

## Como funciona cada achievement

| Achievement | Como ganhar | Níveis |
|---|---|---|
| 🦈 **Pull Shark** | Abrir pull requests que sejam mesclados | 2 / 16 / 128 / 1024 |
| 🤠 **Quickdraw** | Fechar uma issue ou PR em menos de 5 minutos após abrir | único |
| 🎲 **YOLO** | Mesclar um PR sem review | único |
| 👥 **Pair Extraordinaire** | Commits em coautoria (`Co-authored-by`) em PRs mesclados | 1 / 10 / 24 / 48 |
| 🧠 **Galaxy Brain** | Respostas aceitas em GitHub Discussions | 2 / 8 / 16 / 32 |
| ⭐ **Starstruck** | Criar um repositório com muitas estrelas | 16 / 128 / 512 / 4096 |
| 💖 **Public Sponsor** | Patrocinar alguém pelo GitHub Sponsors | único |

## Dicas

- As conquistas levam de alguns minutos a algumas horas para aparecer no perfil.
- Em **Settings → Public profile**, deixe ativa a exibição de *Achievements*.
- **Galaxy Brain** precisa de outra pessoa: responda a pergunta de alguém em um repo com *Discussions* e peça para marcarem sua resposta como aceita (2 aceitas = badge).
- **Starstruck** precisa de 16 estrelas de contas diferentes em um repositório seu.
- **Public Sponsor**: basta patrocinar qualquer dev/projeto a partir de US$ 1 em [github.com/sponsors](https://github.com/sponsors/explore).
